## 主流程（约 5 分钟）

- [ ] WASD 移动，按住右键转向；可以观察两台机柜和水泵，不穿墙、不掉落。
- [ ] 松开右键后点击机柜表面，只出现一个黄色草稿球；坐标对应实际命中点。球中心沿法线偏移只是视觉处理。
- [ ] 输入唯一标题“最终验收-日期-序号”、描述、high；记录 x/y/z。提交后明确提示成功及 ID，球变绿。
- [ ] React 点“刷新问题”，找到同一标题；详情 ID、描述、优先级和坐标一致，状态待处理。
- [ ] 改为处理中，等待保存成功，再改为已解决；刷新浏览器，状态仍已解决。
- [ ] 记下完整 ID，在 Go 终端 Ctrl+C 停止服务；前端保持运行，点击“刷新问题”，看到错误和旧数据提示，编辑被禁用。
- [ ] Go 停止期间刷新整个浏览器，页面可打开并提示连接异常，不白屏。
- [ ] 使用原命令重启 Go，点击“重新获取”；同一 ID 和字段仍存在，状态已解决。不要通过重新提交来模拟恢复。

## 异常与交互（约 5 分钟）

- [ ] 点击另一位置，空标题或仅空格提交：提示必填，没有新记录。
- [ ] 填写表单时按 WASD/R、按右键：不移动场景；点击输入框、优先级和按钮不新增标记。
- [ ] 表单打开时连续点击场景：仍只有一个草稿，不改变草稿坐标；取消或 Esc 后草稿消失，已保存球保留，数据库无新增。
- [ ] 有效提交时快速点击两次：只新增一条，进行中按钮禁用；成功后关闭表单的点击不穿透场景。
- [ ] Go 停止时在 Unity 新建问题并提交：明确失败，输入与草稿保留；重启后先用网页确认未写入，再重试。
- [ ] React 搜索标题、切换优先级和状态，结果正确；无匹配显示空结果，清除筛选恢复。
- [ ] 可选后端校验：打开 8080 辅助页，使用空白标题/错误优先级/缺少坐标/错误状态按钮，应为 400 且列表不增加。
